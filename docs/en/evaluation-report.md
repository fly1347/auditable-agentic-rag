# Evaluation Report

## 1. Evaluation Goals

The final evaluation focuses on four engineering questions:

1. Can the current structure-aware splitter and frozen index reliably complete the 30-question in-domain regression set?
2. What control outcomes do `baseline` and `orchestrated` produce under shared inputs?
3. How much additional latency, token usage, and cost does structured sufficiency introduce?
4. Which conclusions are supported by the current evidence, and which gaps remain?

Evaluation signals remain layered rather than being collapsed into one aggregate score.

Citation Support is a local character/lexical rule intended to provide deterministic audit signals; it is not equivalent to semantic entailment. Conflict does not trigger in the final runs, which only means the current rules did not flag potential conflicts in these two batches.

## 8. RAGAS

The evaluated question sets differ by profile: `baseline` evaluates 29 questions and `orchestrated` evaluates 25. Cross-profile conclusions use the 25 shared questions.

| metric | baseline | orchestrated | delta |
| :-- | --: | --: | --: |
| Context Precision | 0.8734 | 0.9066 | +0.0331 |
| Faithfulness | 0.9691 | 0.9422 | -0.0269 |
| Answer Relevancy | 0.8673 | 0.8303 | -0.0370 |

`orchestrated` improves Context Precision, while Faithfulness and Answer Relevancy do not improve in parallel. Strict evidence control, answer quality, and answer coverage need to be interpreted separately.

The `baseline` Faithfulness scores for the four newly refused questions are 0.3750, 0.2000, 0.2857, and 0.4000, supporting the conclusion that the answers are readable but insufficiently grounded.

## 10. Conclusions and Scope

- `baseline`: higher coverage and lower cost, suitable for general interaction, demos, and batch regression;
- `orchestrated`: stricter evidence control, suitable for higher-risk QA and audit;
- current bottleneck: reachability of core evidence and second-round recovery;
- evaluation scope: this regression set is suitable for in-domain engineering regression and failure diagnosis, not for claims of out-of-domain generalization.
